# Meq3D · landing de ventas

MVP estático y responsive inspirado en la identidad visual de MeqForge.

## Abrir

Abre `index.html` directamente o sirve la carpeta con cualquier servidor estático.

## Despliegue en esta máquina

La configuración operativa para publicar el sitio por Cloudflare Tunnel está documentada en [`deploy/README.md`](deploy/README.md).

## Antes de publicar

1. Completar `STORE_CONFIG` al inicio de `app.js` con los datos verificables del vendedor.
2. Reemplazar las imágenes conceptuales por fotografías reales.
3. Sustituir medidas, materiales, acabados, precios y plazos por datos reales.
4. Para cada producto, registrar autor, fuente, licencia, versión, modificaciones y evidencia.
5. Validar legalmente la declaración de licencias, retracto, garantía y política de privacidad.
6. Conectar el botón de cotización a un canal real solo después de confirmar correo o WhatsApp.

## Datos actuales

- Nombre comercial propuesto: Meq3D.
- Sistema visual: heredado de MeqForge / MeqTec Foundry.
- Catálogo: demostrativo; no está habilitado para venta ni cobro.
- Las solicitudes se guardan únicamente en `localStorage` y pueden copiarse al portapapeles.

## Imágenes

Las cuatro imágenes incluidas fueron generadas para este MVP mediante el generador integrado de imágenes. Representan conceptos originales y no acreditan que exista un archivo 3D imprimible o una licencia comercial; deben reemplazarse o documentarse antes de vender.
